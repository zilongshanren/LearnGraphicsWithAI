# Q: 如何添加一个立方体，放在球的旁边，显示不同的颜色？

## A: 需要改两处代码

### 第一处：添加 Box SDF 函数

在 `sdPlane` 之后，加入长方体的 SDF：

```glsl
// 长方体的 SDF
// center = 中心位置，b = 半尺寸（长宽高各一半）
// 核心思路：把点 p 变换到以 center 为原点的局部坐标，
// 然后计算它在 x/y/z 三个轴上分别"超出"盒子边界多少
float sdBox(vec3 p, vec3 center, vec3 b) {
    vec3 q = abs(p - center) - b;              // 每个轴超出半尺寸的量（负数 = 在盒子内）
    return length(max(q, 0.0))                  // 在外面：欧氏距离到最近角/边/面
         + min(max(q.x, max(q.y, q.z)), 0.0);  // 在里面：最大的负值（最小穿透深度）
}
```

**为什么 Box SDF 比 Sphere 复杂？**

球只需要一个数（到球心的距离），但盒子有 6 个面，每个轴都要独立判断"是否超出边界"：

```
     ┌──────────────┐
     │              │
     │   q < 0      │  ← 在盒子内：q 为负，三个轴的最大负值就是距离
     │   （内部）    │
     │              │
     └──────────────┘
          ↑
     q.x = abs(p.x) - b.x
     在内部时 < 0（没超出边界）
     在外部时 > 0（超出了多少）
```

外部的点，到盒子最近的位置是角、棱或面，用 `length(max(q, 0))` 算欧氏距离；内部的点，取三轴中穿透最浅的那个方向。

### 第二处：在 `scene` 里加入立方体，分配新 ID

```glsl
vec2 scene(vec3 p) {
    float dSphere = sdSphere(p, vec3(0.0, 0.5, 0.0), 0.5);             // 球：原点正上方
    float dBox    = sdBox(p, vec3(1.5, 0.4, 0.0), vec3(0.4, 0.4, 0.4)); // 立方体：球右边 1.5 单位
    float dPlane  = sdPlane(p, 0.0);

    // 三者取最近，带上各自的 ID
    vec2 result = vec2(dSphere, 1.0);                        // ID 1 = 球体（红色）
    if (dBox   < result.x) result = vec2(dBox,   3.0);       // ID 3 = 立方体（新颜色）
    if (dPlane < result.x) result = vec2(dPlane, 2.0);       // ID 2 = 平面（棋盘格）
    return result;
}
```

位置说明：立方体中心设在 `vec3(1.5, 0.4, 0.0)`——球心在 `x=0`，所以立方体在球右边 1.5 个单位；高度 `y=0.4` 恰好让底面落在地面上（半尺寸 `b.y=0.4`，`0.4 - 0.4 = 0`）。

```
俯视图（y 轴朝上，看 xz 平面）：

    z
    ↑
    │
    │    ●        ■
    │  球体      立方体
    │ (0,0.5,0)  (1.5,0.4,0)
    └───────────────────→ x
         0        1.5
```

### 第三处：在着色部分加 ID 3 的颜色

```glsl
vec3 baseColor;
if (hit.y == 1.0) {
    baseColor = vec3(0.9, 0.2, 0.1);       // ID 1 = 球体：红色
} else if (hit.y == 3.0) {
    baseColor = vec3(0.2, 0.5, 0.9);       // ID 3 = 立方体：蓝色
} else {
    // ID 2 = 平面：棋盘格
    float checker = mod(floor(hitPos.x) + floor(hitPos.z), 2.0);
    baseColor = mix(vec3(0.8), vec3(0.3), checker);
}
```

### 可调整的参数

| 参数 | 位置 | 效果 |
|------|------|------|
| `vec3(1.5, 0.4, 0.0)` | 立方体中心 | 改 x 值调左右距离，改 z 值让立方体往前/后移 |
| `vec3(0.4, 0.4, 0.4)` | 半尺寸 | 改成 `vec3(0.2, 0.6, 0.4)` 变成长方体 |
| `vec3(0.2, 0.5, 0.9)` | 立方体颜色 | 任意 RGB |

### 这个修改体现的架构优势

**只改了 `scene` 函数（加一行 SDF + 一次比较）和着色（加一个 `else if`），Ray Marching 主循环、法线计算、光照函数完全不用动。**

这就是 SDF 场景描述的核心优雅性：渲染系统和场景内容完全解耦。
