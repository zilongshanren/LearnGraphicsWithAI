# Q: 屏幕小怎么理解？没有透视除法，近大远小是怎么实现的？

## A: 透视除法是在模拟"从一点看出去"，Ray Marching 天然就是

### 没有透视除法的原因

传统管线的透视除法（除以 w）是为了把 3D 坐标压缩到 NDC 空间，本质上是**模拟"从一个点看出去"**这件事。

Ray Marching 里，"从一个点看出去"是**天然成立的**——所有射线本来就从同一个 `rayOrigin` 出发。透视已经物理地内嵌在射线的构造方式里，不需要透视除法。

### "屏幕小"的真正含义

近大远小 = **远处物体在屏幕上占的像素少**。

用"张角"来理解：从摄像机看出去，近处的物体"撑开"的角度大，远处的小：

```
        ←── 0.5 ──→← 0.5 →  （两个球半径相同）
              球 A              球 B

    📷──────────────────────────────
        ←  z=2  →←     z=8     →

    球 A 的张角 ≈ atan(0.5/2) ≈ 14°
    球 B 的张角 ≈ atan(0.5/8) ≈  4°
```

### 张角决定占多少像素

屏幕上每个像素 = 一条固定方向的射线。物体占多少像素，取决于它的边缘落在哪两条射线之间：

```
屏幕像素（每个像素 = 一条射线）：

    │·│·│·│·│·│·│·│·│·│·│
     1  2  3  4  5  6  7  8  9

球 A（近）：左边缘在射线 3，右边缘在射线 7 → 占 4 个像素 → 大
球 B（远）：左边缘在射线 4，右边缘在射线 6 → 占 2 个像素 → 小
```

### 完整逻辑链

```
所有射线从同一点出发，方向均匀分布在屏幕上
                ↓
每个像素 = 一个固定方向的射线
                ↓
近处物体张角大 → 覆盖更多射线 → 占更多像素 → 看起来大
远处物体张角小 → 覆盖更少射线 → 占更少像素 → 看起来小
                ↓
              近大远小 ✅
```

### 一句话总结

透视除法是传统管线用数学**模拟**"从一点看出去"的手段；Ray Marching 直接在物理层面上实现了它——所有射线从同一点发散，透视天然存在。
