# Q: 透视这样理解对吗？同样的步长 1，中间往前走的 z 更长，两边更短，所以是近大远小？

## A: 方向对，中间缺一步逻辑

### 你的观察完全正确

"同样的步长，中间 z 推进更多，两边 z 推进更少"——正确：

```
走同样的 1 步：

中心射线 normalize(0, 0, 1)       → (0,    0,    1.0)  z 推进 = 1.0
边缘射线 normalize(0.89, 0.5, 1)  → (0.63, 0.35, 0.7)  z 推进 = 0.7
```

### 缺了一步：到达同一个物体需要走更多步

真正产生近大远小的逻辑链：

```
场景里有一堵墙在 z = 5 处：

中心射线 z 每步推进 1.0 → 走 5 步到达墙
边缘射线 z 每步推进 0.7 → 走 5 ÷ 0.7 ≈ 7.1 步才到达墙

边缘射线走了更多步 → 感知距离更远 → 渲染出来更小
```

```
摄像机视角：

         墙的实际位置（z=5）
              │
    ↗─────────┤  边缘射线：走了 7.1 步才到
    │         │
    📷 ────────┤  中心射线：走了 5 步到
    │         │
    ↘─────────┤  边缘射线：走了 7.1 步才到
              │
    ────────────────→ z
    0         5
```

### 完整逻辑链

```
边缘 uv 不为零
  → 射线方向斜
  → 每步 z 推进更少
  → 到达同一个 z 位置需要更多步
  → 射线"感知"的距离更长
  → 渲染出来物体更小
  → 近大远小 ✅
```

### 一句话总结

"z 推进更少"是原因，"近大远小"是结果，中间还差一步——"到达同一个物体需要走更多步"。加上这一步逻辑就完整了。
