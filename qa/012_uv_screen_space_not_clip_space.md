# Q: 这个 uv 是投影空间的吗？

## A: 不是，是屏幕空间（Screen Space）

### 传统渲染管线里的"投影空间"

传统管线的坐标变换链：

```
模型空间 → 世界空间 → 观察空间 → 裁剪空间(Clip) → NDC → 屏幕空间
         Model矩阵   View矩阵    Projection矩阵    /w    视口变换
```

"投影空间"通常指 **Clip Space 或 NDC**——把 3D 场景投影到标准化立方体 `[-1,1]³` 里的结果，是顶点着色器输出 `gl_Position` 所在的空间。

### 这里的 uv 是什么空间

```glsl
vec2 uv = (fragCoord - 0.5 * iResolution.xy) / iResolution.y;
```

这是从 **fragCoord（屏幕像素坐标）** 直接推导出来的，没有经过任何投影矩阵。它就是屏幕上的位置，以屏幕中心为原点，单位是"屏幕高度的一半"。

### 和传统管线的本质区别

```
传统管线：  3D顶点 → [Model/View/Projection 矩阵] → 屏幕像素
                      正向：3D → 2D

Ray Marching：屏幕像素 → [手动构造射线] → 打进 3D 场景
                          反向：2D → 3D
                               ↑
                          uv 就是这里
```

Ray Marching 是**反过来走的**——从屏幕出发往 3D 空间射线，根本不需要投影矩阵。`uv` 只是屏幕坐标的一个方便表示，不属于传统管线里任何标准的变换空间。

### 一句话总结

这个 `uv` 是屏幕空间坐标（原点在屏幕中心），和传统管线的投影空间（Clip Space / NDC）是两回事。
