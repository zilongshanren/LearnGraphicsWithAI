# Q: 详细解释 scene 函数——SDF 和返回不同物体 ID/距离的判断逻辑

## A: SDF 到底在算什么

SDF（Signed Distance Function）回答一个简单的问题：**给定空间中任意一点 p，它离物体表面有多远？**

### 球体 SDF

```
float sdSphere(vec3 p, vec3 center, float radius) {
    return length(p - center) - radius;
}
```

以球心 (0, 0.5, 0)、半径 0.5 为例：

```
                    · p1 在外面
                  ╱ length(p1 - center) = 1.2
                ╱   SDF = 1.2 - 0.5 = 0.7 ✅ 正数
              ╱
        ┌───────────┐
       ╱   ·        ╲        · p3 在表面上
      │   center     │        length(p3 - center) = 0.5
      │  (0,0.5,0)   │        SDF = 0.5 - 0.5 = 0.0 ✅ 零
       ╲     ·      ╱
        └───────────┘
              p2 在里面
              length(p2 - center) = 0.2
              SDF = 0.2 - 0.5 = -0.3 ✅ 负数
```

| 位置 | `length(p - center)` | `- radius` | SDF 值 | 含义 |
|------|---------------------|-----------|--------|------|
| 物体外面 | 1.2 | - 0.5 | **+0.7** | 离表面还有 0.7 |
| 表面上 | 0.5 | - 0.5 | **0.0** | 恰好在表面 |
| 物体里面 | 0.2 | - 0.5 | **-0.3** | 在内部 0.3 深处 |

**Signed（有符号）的含义**：正数 = 外面，负数 = 里面，零 = 表面。

### 平面 SDF

```
float sdPlane(vec3 p, float height) {
    return p.y - height;
}
```

平面在 y = 0：

```
  ↑ y
  │
  │  · p (y=1.5)     SDF = 1.5（离平面 1.5 远）
  │
  │  · p (y=0.3)     SDF = 0.3（离平面 0.3 远）
  │
──┼──────────────── y = 0 平面（SDF = 0 的地方）
  │
  │  · p (y=-0.3)    SDF = -0.3（在平面"里面"）
```

## scene 函数做了什么

场景里有两个物体。对于空间中任意一点 p，分别问两个物体"你离我多远"：

```
vec2 scene(vec3 p) {
    float dSphere = sdSphere(p, ...);   // 问球体：你离我多远？
    float dPlane  = sdPlane(p, 0.0);    // 问平面：你离我多远？
    ...
}
```

### 具体例子：p = (0, 2, 0)

```
  ↑ y
  │
  │  ★ p = (0, 2, 0)
  │  │
  │  │ dSphere = length((0,2,0)-(0,0.5,0)) - 0.5
  │  │         = 1.5 - 0.5 = 1.0
  │  │
  │  ○ 球体 (球心 y=0.5, 半径 0.5, 顶部 y=1.0)
  │  │
  │  │ dPlane = 2.0 - 0 = 2.0
  │  │
──┼──┼─────── 平面 y=0
```

### 为什么取最小值

**Ray Marching 需要知道"离最近的任何物体有多远"——这决定了射线能安全走多远。**

```
  ★ p = (0, 2, 0)
  │
  │ dSphere = 1.0 ← 更近！
  │ dPlane  = 2.0
  │
  │ 安全步进距离 = min(1.0, 2.0) = 1.0
  │
  │ 如果错误地走了 2.0 步 → 会穿过球体！
  │ 走 1.0 步是安全的 → 保证不会穿过任何物体
```

用安全球来理解：

```
            安全范围（半径 = 1.0）
            ┌─────────────┐
           ╱               ╲
  ────────╱────★ p──────────╲────
          ╲   ↑ 这个圆内     ╱
           ╲  没有任何物体  ╱
            └──────────────┘
                  │
                  ↓
         ┌───────────┐
         │   球体     │ ← 恰好在安全范围边缘
         └───────────┘
     ──────────────────── 平面 ← 还在安全范围外面
```

### 为什么要带物体 ID

取了最小值后知道"最近物体有多远"，但 Ray Marching 最终击中物体时，还需要知道**击中的是哪个物体**——才能上正确的颜色：

```
    if (dSphere < dPlane) {
        return vec2(dSphere, 1.0);   // 球体更近 → 返回球体距离和 ID
    } else {
        return vec2(dPlane, 2.0);    // 平面更近 → 返回平面距离和 ID
    }
```

ID 在最终着色时使用：

```
    if (hit.y == 1.0) {
        baseColor = vec3(0.9, 0.2, 0.1);   // ID 1 → 红色球体
    } else {
        baseColor = 棋盘格;                  // ID 2 → 灰色平面
    }
```

### 完整流程

```
一条射线从摄像机出发，走了很多步...

第 1 步: p = (0, 1, -3)     scene(p) → (1.73, 1)   走 1.73
第 2 步: p = (0, 1, -1.27)  scene(p) → (0.58, 1)   走 0.58
第 3 步: p = (0, 1, -0.69)  scene(p) → (0.21, 1)   走 0.21
第 4 步: p = (0, 1, -0.48)  scene(p) → (0.08, 1)   走 0.08
  ...
第 N 步: p ≈ (0, 1, -0.37)  scene(p) → (0.0008, 1) < 0.001 → 击中！

击中了 ID = 1（球体）→ 涂红色 + 计算光照
```

**总结**：每个物体各自报告距离，取最近的，带上 ID，供后续着色使用。加新物体只需多加一个 SDF 函数和一次比较。
