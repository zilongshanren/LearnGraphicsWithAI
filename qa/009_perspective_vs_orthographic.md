# Q: `normalize(vec3(uv, 1.0))` 为什么是透视投影？ray 不是垂直于屏幕向前的吗？

## A: 正交 vs 透视的区别

"ray 垂直于屏幕向前"描述的是**正交投影**，而这行代码做的是**透视投影**。

```
正交投影（所有射线平行）：

    📷 摄像机平面
    │→→→→→→→→→→→→→→→ 所有射线方向都是 (0,0,1)
    │→→→→→→→→→→→→→→→
    │→→→→→→→→→→→→→→→
    │→→→→→→→→→→→→→→→

    近处和远处的物体大小相同（工程图纸常用）


透视投影（射线从一个点发散）：

        ↗→→→→→→  右上角像素
       ↗
    📷 → → → →  中心像素，方向 (0,0,1)
       ↘
        ↘→→→→→→  右下角像素

    越靠边的像素射线偏离正前方越多 → 近大远小
```

## 这行代码为什么产生透视

```glsl
vec3 rayDir = normalize(vec3(uv, 1.0));
```

`uv` 是屏幕坐标，中心是 `(0,0)`，边缘是 `(±0.89, ±0.5)`：

| 像素位置 | uv | rayDir |
|----------|-----|--------|
| 中心 | (0.0, 0.0) | normalize(0, 0, 1) = **(0, 0, 1)** 正前方 |
| 右边 | (0.5, 0.0) | normalize(0.5, 0, 1) ≈ **(0.45, 0, 0.89)** 偏右 |
| 角落 | (0.89, 0.5) | normalize(0.89, 0.5, 1) ≈ **(0.63, 0.35, 0.7)** 偏右上 |

所有射线共用同一个 `rayOrigin`，但方向不同：

```
              ↗  角落射线（偏右上）
             ↗
    📷 ──────→  中心射线（正前方）
             ↘
              ↘  角落射线（偏右下）

    起点相同，方向发散 = 透视投影
```

**关键**：所有射线从同一个 `rayOrigin` 出发，方向各不相同——这就是透视的本质。

## 如果要写成正交投影

正交投影的射线方向**全部相同**，但起点随 uv 偏移：

```glsl
// 正交投影
vec3 rayOrigin = vec3(uv, -3.0);        // 起点随像素偏移
vec3 rayDir    = vec3(0.0, 0.0, 1.0);   // 方向全部平行向前
```

```
正交：                  透视（当前代码）：

起点→ · → → → →         · ↗
起点→ · → → → →         ·→
起点→ · → → → →    📷 ──·──
起点→ · → → → →         ·→
起点→ · → → → →         · ↘
     平行，不汇聚         从一点发散
```

## 一句话总结

不是"ray 垂直于屏幕"，而是"所有 ray 从同一个点出发"。起点相同 + 方向随 uv 偏移 = 自然产生透视（近大远小）效果。
